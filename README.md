# Simulacra

Prototipo desktop di Simulacra, gioco di Matteo Perlini. Due persone giocano a turno nello stesso browser. Le schermate di passaggio tengono coperte le mani.

Il prototipo usa la configurazione illustrata nel regolamento 5.1 e quindici incantesimi, incluso Colpo Arcano. Ogni Arcimago pesca sei carte dal proprio grimorio di prova mescolato. Ricaricare la pagina avvia una nuova partita. Il piano di sviluppo è in PROGETTO.md.

Per avviare in locale, eseguire `python -m http.server 8000` e aprire `http://localhost:8000/`.
